# Project 5 -- Meridian UAV Services: the DEPLOYED app's dependencies.
#
# Streamlit Community Cloud looks for a dependency file beside the entry point
# (this folder) before the repository root, so this file is what the live demo
# installs. It is deliberately separate from python/requirements.txt, which is
# the analysis environment (model, SQL access) and uses floors, not pins.
#
# PINNED, unlike the analysis file, because a deployment should run exactly
# what was verified. Cloud reinstalls dependencies whenever it rebuilds the app,
# so with floors an untested release would reach the demo unattended. Upgrade
# these deliberately, re-run streamlit/validate_app.py, then change them here.
# Both are the versions the app was verified on (2026-09-27), on Python 3.12.
#
# Only what app.py and data_access.py import. The app reads the committed CSV
# extracts in data_exports/ -- there is no SQL Server on Cloud -- so pyodbc,
# scikit-learn and matplotlib are left out; the app never imports the last two.
#
# Streamlit must be >= 1.49: app.py passes st.dataframe(width="stretch"), and
# every release from 1.30 to 1.48 raises TypeError on it at the first screen.

streamlit==1.64.0
pandas==3.0.6
